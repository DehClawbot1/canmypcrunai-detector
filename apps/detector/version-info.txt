#
# An executable carrying no CompanyName, ProductName or FileDescription is a
# heuristic red flag: practically all legitimate software ships this resource,
# and its absence is one of the signals reputation systems weigh. Filling it in
# does not replace code signing, but it removes an easy reason to be suspicious.
#

  ),
  kids=[
